## 1. What the source says (quoted)

relay-r1 §6: "The `Gate` is a record of facts gathered by effects and one pure function `Decide(Gate) Result` ..., so `relay gate <row>` by hand and the night's own gate are the same code." The seven checks in order: exit, commit, clean, origin ("`git for-each-ref refs/remotes` equals the snapshot taken at stage"), touch ("every path in `git diff --name-only <base>...<branch>` matches a may-touch entry"), acceptance ("every line re-run in the worktree with `/bin/sh -c`, a 900 s timeout ... a line that fails but whose exit and last line equal its baseline on main is `same-as-main` only when the packet wrote `as main`, otherwise `red`"), merge ("`git merge --no-ff --no-commit <branch>` in the root, the verify line, then `git commit`; on red, `git merge --abort`"). "a gate whose facts could not be gathered is `unrun`, never a pass". §8: "Worktrees live at `<repo>/.claude/worktrees/<id>` on branch `<id>` ... excluded from status via `.git/info/exclude`) and are removed only by `relay clean --merged`, never by the night." §11: "the string `push` in Go source appears only in `internal/hooks/guards.go`, the pre-push hook text in `internal/effects/git.go`, and their tests".

## 2. Rulings

D2: the gate is the driver's. D22 (recommended, unruled; built as recommended): merge as `--no-commit`, verify, commit, else `--abort`; no history rewrite exists in this binary (no `reset --hard`, no `rebase`, no `--amend` anywhere in Go source, and `TestNoRewrite` greps for them). R25-91 (4): the pre-push hook refuses every push with one line naming the relay. A hand `gate <row>` with no `stage` ledger line skips the `exit` check as `skipped` (not `unrun`) and takes `commit` as "the branch has commits beyond its merge-base with the base"; the acceptance rerun happens in the row's worktree when it exists, else in a temporary detached worktree `.claude/worktrees/gate-<id>` removed before exit, even on error.

## 3. Interfaces (signatures, not prose)

- `effects.Git` gains: `WorktreeAdd(dir, path, branch, base string) error`; `WorktreeAddDetached(dir, path, ref string) error`; `WorktreeRemove(dir, path string) error`; `Worktrees(dir) ([]Worktree, error)`; `DiffNames(dir, base, branch string) ([]string, error)` (three-dot); `MergeNoCommit(dir, branch string) error`; `MergeAbort(dir string) error`; `Commit(dir, msg string) (sha string, err error)`; `InstallPrePush(path string) error` (writes `.git/hooks/pre-push` for that worktree via `git rev-parse --git-path hooks`, mode 0755, body `#!/bin/sh` and `echo "relay: push refused" >&2; exit 1`); `Exclude(dir, pattern string) error` (`.git/info/exclude`, idempotent). The fakes record each call and answer from maps.
- `internal/night/stage.go`: `func Stage(fx effects.Effects, rp *RowPlan) (*Staged, error)`: refuses an existing worktree or branch, a lock held for the path (`<state>/locks/<sha1 of path>`), or a live claude whose cwd is the path; then `Exclude`, `WorktreeAdd`, `InstallPrePush`, the origin snapshot, `head_before`, the `stage` ledger line; returns `Staged{Path, Branch, Base, HeadBefore, Origin map[string]string, Lock}`; `(*Staged) Unlock()`.
- `internal/gate/gate.go`: `func Gather(fx effects.Effects, st *Staged, p *packet.Packet, baseline []relay.Check, exit *ExitFacts) relay.Gate` (`ExitFacts{Seen, IsError bool}`, nil for a hand gate); `func Run(fx, ...) (relay.Result, relay.StopReason, relay.Gate)` = `Gather` then `relay.Decide`, one `gate` ledger line per check and a `touch` line naming any path outside may-touch; `func MergeIfGreen(fx effects.Effects, root string, g relay.Gate, branch, verify string) (sha string, err error)`: refuses unless `relay.Decide(g)` is `Green` (the guard `TestMergeNeedsGreen` names), then D22's sequence; the post-merge verify line is the row's `verify` (`auto` → `make check` when `make -n check` succeeds).
- `cmd/relay/main.go`: `gate <row> [--json]` exit 0 green, 1 red or failed, 2 unrun or usage; the JSON is the `relay.Gate` plus `result` and `reason`; `clean --merged [--json]` removes worktrees whose branch is an ancestor of `main`, prints each path, never removes the row's branch.
- Tests, each in a `t.TempDir()` git repo with a bare file remote: `TestPrePushRefuses` (`git push` exits non-zero after `InstallPrePush`); `TestNoPushPath` (walks `*.go`, allows the string `push` only in `internal/hooks/guards.go`, `internal/effects/git.go` and `_test.go` files); `TestNoRewrite`; `TestMergeNeedsGreen`; `TestOriginMovedStops` (a remote ref moved between stage and gate → `Failed, OriginMoved`); `TestTouchSet` (a path outside may-touch → `Red`, named); `TestAcceptanceSameAsMain` (`as main` honoured, plain `reads` not); `TestMergeAbortOnRedVerify` (the root returns to its pre-merge head, the branch untouched); `TestGateTempWorktreeRemoved`.
