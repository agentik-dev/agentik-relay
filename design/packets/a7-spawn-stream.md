## 1. What the source says (quoted)

relay-r1 §7: the spawn block, "with every `CLAUDE*` variable stripped from the environment ... and `RELAY_ROW=<id>` added"; "The stream parser reads `system/init` (session_id, model), `assistant` (usage per message, tool_use blocks, `parent_tool_use_id` for builders), and `result` (subtype, num_turns, total_cost_usd, is_error, permission_denials, duration_ms)"; "a turn is one deduplicated assistant message; context is the last assistant message's input plus cache creation plus cache read"; "at 80% of the row's context a `ceiling` line and a notify; at 100% SIGTERM, thirty seconds, SIGKILL, `ceiling-kill`; the wall clock the same way, `wall-clock`"; "After exit the transcript's `subagents/` directory is read for the builders' burn and nothing else; the transcript body is never read". §11: "a fake `claude` ... emits canned stream-json from a fixture, writes a transcript tree with `subagents/`, commits in its cwd".

## 3. Interfaces (signatures, not prose)

- `internal/stream`: `type Event struct{ Type, Subtype string; SessionID, Model string; Usage *Usage; Tools []ToolUse; ParentToolUseID string; NumTurns int; CostUSD float64; IsError bool; Denials int; DurationMS int64; ResultTail string; MessageID string; Raw json.RawMessage }`; `type Usage struct{ Input, CacheCreate, CacheRead, Output int }`; `type ToolUse struct{ Name, Summary string }` (the summary is the first 80 bytes of the command or path, no prompt text); `type Tally struct{ Turns, Context int; CostUSD float64; LastTool string; Builders map[string]int; ResultSeen bool; Result *Event }`; `func Parse(r io.Reader, onEvent func(Event, Tally)) (Tally, error)` reads line by line, tolerates a non-JSON line (counted, never fatal), deduplicates turns by `MessageID`, counts a message with a `ParentToolUseID` under `Builders`; `(Tally) Line(ceiling int) string` renders `turn N: <tool> "<summary>"; context 71k/130k; $1.20`.
