3. **Act 2, the reading.** `(*Packet).OrdersPerAct(line)` is the place, `wall` or `§N`, of the first clause ordering `line` per act; "" for none or an empty `line`. It reads the wall, then §2, §3, §5, §6 (§1 and §4 quote); text in double quotes outside code spans, closed on its line, is dropped first. A clause ends at a newline, or outside a code span at `;` or a `.` before a space or the end, except the `.` of `e.g.` or `i.e.`. It orders `line` when (a) a code span in it holds `line`'s words as a contiguous run, words starting with `-` dropped from both (`make -k check-fast` holds `make check-fast`; `make -k check CHECK_GATES="vet lint"` holds `make check`; a suite spelled as another line is out of reach); (b) its text outside code spans holds, case aside, `each act`, `every act`, `per act`, `after an act`, `act gate`, or `acts` before a number (`Acts 3 and 4`); (c) **the false-positive guard**: that text holds, case aside, none of the words `never`, `no`, `not`, `don't`, `once`, `last`, `final`.
