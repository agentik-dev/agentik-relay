## 2. Rulings

Record each choice in the charter, at most ONE fork. Each act's test reproduces its finding FIRST (red on `main`), then the fix. The owner's push word stands (`push` denied only under `RELAY_ROW`); do not reopen it.

0. **No global config in the runners (ADV12-1; ADV12-10's warning red).** `gitCmd` and `LsRemote` set `GIT_CONFIG_GLOBAL=/dev/null` beside `GIT_CONFIG_NOSYSTEM=1`, and add `-c core.attributesFile=/dev/null -c core.excludesFile=/dev/null` (a global ignore must not hide an untracked file from `clean`). The committer identity is read once at process start, before any spawn (`effects.Identity`), and passed to the merge's commit by `-c user.name= -c user.email=`; an empty one makes the merge `unrun`, reason `no-identity`. `TestAR21_0_GlobalConfigIgnored` (review test 1: `GIT_CONFIG_GLOBAL` unset, `$HOME/.gitconfig` holding a smudge filter, an `insteadOf` and an `excludesFile`); drop the `/dev/null` pin from the one world that proves it.
1. **Config bound once per root, program keys refused (ADV12-2; ADV12-10's alternates).** The digest's baseline is bound at the first stage of a root in this process, held in memory beside `ownMerge`; a later stage, the gate and the merge compare against it, and the merge compares again after `mergedVerify`: a change is `unrun`, reason `git-state-moved`; after `mergedVerify` the merge is undone (`reset --hard` to the recorded main). Stage, gate and merge refuse (`unrun`, reason `git-config-program`, before any spawn when at stage) a key in the local or any worktree config matching `filter.*`, `merge.*.driver`, `diff.*.textconv`, `diff.*.command`, `core.sshCommand`, `core.gitProxy`, `core.askPass`, `credential.*`, `gpg.*.program`, `include.*`, `includeIf.*`, `url.*.insteadOf`, `url.*.pushInsteadOf`, `remote.*.uploadpack`, `remote.*.receivepack`. No repo in the queue needs one; a repo that does gets a queue key in a later packet. `GitStateDigest` adds `objects/info/alternates`. `TestAR21_1_ConfigBetweenRows` (review test 2), `TestAR21_1_ProgramKeysRefused` (one table row per pattern).
2. **One relay per account (ADV12-3, a fork-storm door; ADV12-8 next to it).** `run`, a measuring `plan` and `resume` refuse ANY live holder, ancestor or not, exit 2, naming its pid. The holder keeps an exclusive `flock` on `relay.pid` for its life, so the next comer's `LOCK_NB` fails and a truncated file refuses still; a dead holder's lock dies with it. No spawned child inherits the fd; `resume` clears close-on-exec so the lock outlives its exec. No bypass flag: a flag a sitting can type is no lock, and `--parallel` is the concurrency door. A refused `resume` prints the line it would exec (as `--print` does), so the door stays obvious. The Write door also denies `night.PidDir()`, compares roots after `filepath.EvalSymlinks` (`/private/tmp`), and expands `~/`. `TestAR21_2_DetachedNestedRelay` (review test 3), `TestAR21_2_SecondNightRefused`, `TestAR21_2_TruncatedPidStillRefuses`, `TestAR21_2_PidDirDoor`.
3. **The shell reader (ADV12-4, -5).** The guards read `$'…'` with its backslash escapes; `packet.Unbounded` refuses `$'` outright. Inside `((…))`, `$((…))` and after `let`, `<<` is a shift, never a heredoc. `TestAR21_3_AnsiCQuote` (`echo $'\'' ; git push origin main` and `; relay run` denied in a sitting; the acceptance cell refused), `TestAR21_3_ArithmeticShift`.
4. **A `-run` that matches every test, one package (ADV12-6; ADV12-10's endless read).** `runProbes` adds `TestZqzvq`, `Test_qzvq`, `Test9qzvq`, `ExampleZqzvq` and `FuzzZqzvq`; a `go test` line names ONE package. A read verb's operand under `/dev/` (but `/dev/null`) is refused. `ar20-fixes-adv11` joins `spent` (its lines name several packages); `TestAR20_5_SpentStems` follows. `TestAR21_4_RunProbes` (`Test[A-Z]` and `^(Test|Example)[A-Z0-9_]` refused), `TestAR21_4_OnePackage`, and this packet's own lines pass.
5. **The ledger is a claim, never a binding (ADV12-7).** A `Staged` read from the ledger (`StagedFromLedger`: the hand gate, `relay resume`, a restarted process) binds main by refname, the digest (act 1) and the remote URLs afresh; its `main_sha`, `state_digest`, `remote_urls` and `origin_refs` are never compared as truth. A dependency is satisfied by `landed` (git), or by a green verdict this process wrote (memory); a green ledger line counts only for a row with no branch (a packet writer on `main`), and `plan` labels that dependency `ledger-green`. `TestAR21_5_LedgerRowBoundAfresh`, `TestAR21_5_ForgedGreenNotLanded`.
6. **The design.** §6, §8, §10 and §15 gain acts 0 to 5; §8 keeps "one relay per account" as the holder rule; §11's table names every `TestAR21_`. Deferred in §15: ADV12-9, ADV12-10's `rsync` text, ADV11-8, -13, -15 and -18 to -20.
7. **The model (only before turn 70).** `Night.tla` gains `DetachedRun` (a child's relay with its env stripped, not an ancestor) and `PidGuard` (any live holder refuses); `Night.cfg` stays clean and a new storm config with the ancestors-only rule finds the storm.
