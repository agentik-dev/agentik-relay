## 2. Rulings

Decide inside the design, record each choice in the charter, at most ONE fork. One commit per act with its design clause; act 0 first. The e2e is `cmd/relay/e2e_test.go` under the build tag `e2e` (never in `go test ./...`), in package `main` (it reuses `outsideCheckout` and `TestMain`); each case builds its fixture and state under `t.TempDir()` and runs the binary with an env built from scratch: `PATH` the fakes' dir then the process's own, `HOME` a temp dir holding a `.gitconfig` with a user, `GIT_CONFIG_NOSYSTEM=1`, `XDG_STATE_HOME` the case's state, no `RELAY_*`, no `CLAUDE*`; every run `--no-tmux --rows <the case's>`. Time: the watchdog polls every 60 s and the breaker every 30 s, so a stall costs one poll and an open one; `make e2e` finishes under 8 minutes here (`-timeout 12m`; the gate's cap is 900 s).

0. **The fixture and the fakes.** `fixture(t)`: a temp git repo on `main` with `relay/queue.yaml` (defaults `verify: auto`, `merge: merge-on-green`, `wall: 2m`), `Makefile` (`check: ; @test ! -e history/sessions/NEXT`), one packet per row under `design/packets/` (six rows, six sections; may touch `acts/*.txt`; acceptance `test -f acts/<row>-1.txt && echo ok` reads `ok`), the rows per case. The fake claude (`internal/effects/testdata/fakeclaude`; the unit tests' knobs kept) gains `FAKECLAUDE_MODE` (ok, red, stall, orphan, hang, hold, next), `FAKECLAUDE_ACTS` (n files `acts/<row>-<k>.txt`, one commit each), `FAKECLAUDE_PROMPT` (stdin copied there: RULES and CONTEXT read), `FAKECLAUDE_PIDFILE`, `FAKECLAUDE_ENVDUMP`; a fake `sysctl` answers `-n vm.loadavg` from the file `FAKE_LOAD` names, else execs the real one. `TestE2E_0_FixtureOnly`: every path a case opens is outside the checkout, the env dump holds `RELAY_ROW` and `RELAY_MEASURE_DEPTH=1` and no `CLAUDE*`, the fixture has no remote, the real queue's mtime is unchanged, the prompt copy names the row's packet and the queue's words.
1. **The full night.** `TestE2E_1_FullNight`: r1 (two acts), r2 `depends_on: [r1]`, r3 `parked`; exit 0; r1 and r2 green and merged, r3 skipped `parked`; the ledger's shape (`night-open`; `plan` per unparked row; `stage`, `spawn`, `exit`, `gate`, `sitting` per run row; `merge` twice; `stop` `queue-empty`; `night-close`); each `sitting` line carries `gate.verify`, `orphans: 0`, `breaker.opens: 0`; main's first-parent history: two merge commits, r1 then r2, each second parent the row's tip; `report` names both shas; `status` reads `stopped:queue-empty`; no lock left under the state's locks.
2. **Red and next.** `TestE2E_2_Red`: r1 `mode red` (a file outside may-touch): `touch` red, the row red, its `sitting` line without `stop`, `relay resume r1` printed, r2 (on r1) skipped, the night `stopped:gate-failed-dependency`, exit 1. `TestE2E_8_Next`: `mode next` writes and commits `history/sessions/NEXT`: the gate green (the touch set admits it), the merge's verify red, the `merge` line `aborted`, the branch kept, main's history unchanged.
3. **Stall, orphan, chaos, the wall.** `TestE2E_3_Stall`: `mode stall` (no commit, no write, no CPU), `--stall-seconds 1`: within 90 s the row red `stalled` with `stall: {head, mtime, cpu_s, at}` on its line, the pid file's process dead. `TestE2E_4_Orphan`: `mode orphan` forks `sleep 300` (stdout to `/dev/null`) in its group and exits green: `orphans: 1`, the row red, the sleeper dead after the sweep. `TestE2E_5_Chaos`: `mode hang` writes its pid, forks the same sleeper, sleeps; the test SIGKILLs the pid once the file appears: the `exit` line's `error` starts `signal:`, `orphans: 1`, the row `failed stream-error` (§1: no result event), the night `stopped:stream-error`, the sleeper dead. `TestE2E_6_Hold` (ar10's gap 2, ADV6-7): `mode hold` forks a sleeper that keeps stdout and exits green; the row's `budget: {wall: 90s}`: the sitting ends within 150 s, `failed wall-clock`, the night `stopped:wall-clock`, no live process; AR13 turns it into `orphans` in seconds.
4. **The soak.** `TestE2E_7_Soak`: five independent rows, `--parallel 1`; `FAKE_LOAD` starts at `{ 99.0 1.0 1.0 }`; on the first `breaker` line (`state: open`) the test writes `{ 0.5 0.5 0.5 }`, so the plan's first line opens the breaker once, closed at the next poll (a spawn-time open has no seam from outside; `TestAR10_5_StillOpenSpawnStopsLoad` holds it): every `plan` line carries `breaker.opens: 1`, `wait_s` 30 or more, `load` 99; five green sittings and five merges in order, `orphans: 0` and `breaker.opens: 0` on every `sitting` line, `status.json` present, no lock files left, an env dump per row.
5. **The design.** `Makefile` `e2e`: the one line `go test -tags e2e ./cmd/relay -run 'TestE2E_' -count=1 -v -timeout 12m` (the test builds the binary and the fake claude into its temp dir), never in `check`; §11's end-to-end paragraph names the nine `TestE2E_` cases and the fake's knobs; §9 gains `make e2e`; §16 names, per case, the model invariant it exercises.
