## 1. What the source says (quoted)

relay-r1 §3: "Strict YAML subset (D12; conventions §3): mappings, scalars, flat lists, comments; the binary ships its own parser with a corpus of accepted and refused documents and takes no dependency" and the schema block (`version`, `defaults`, `words`, `rows` with `id, packet, depends_on, base, model, budget, merge, device, parked`). "Validation: ids unique and equal to the packet's stem; every packet exists and parses (§2); `depends_on` and `base` name rows or satisfied externals; no cycle (`base` counts as an edge); `merge-on-green` only when the row's base is `main`; `device` is `never` or a non-empty string." §2, the table: may touch is "backtick spans, each a path or a per-segment glob (`*` inside one segment, a trailing `/` means everything below); 'Nothing else' closes the set"; acceptance is "items split on `;`, each `` `shell line` <expectation> ``; expectations: `reads <value>` ..., `reads <n> or more`, `under <n>`, `exits <n>`, `as main`; `\|` inside a span is a pipe"; budget is "`<n> turns, <n>k context`". "`internal/packet` parses the table and the headings and refuses anything else ... Prose is never validated."

## 2. Rulings

D4: the queue file is `relay/queue.yaml` in the target repo. D17 (recommended, unruled; built as recommended): no YAML dependency; `go.mod` stays without a `require`. D12 and conventions §3: the subset is mappings, scalars (plain, single- and double-quoted, integers, booleans, durations as strings), flat lists (block `- x` and flow `[a, b]`), flow mappings one level deep (`{turns: 100, usd: 15}`), comments; anchors, multi-line scalars, nested flow, tabs and duplicate keys are refused with the line number. Dependency *satisfaction* (ledger, ancestor) is A5's: this packet resolves only structure, and an external id (absent from the queue) is reported as `external`, never invalid. Baselines are A5's: `plan` here prints each row's state (`valid`, `invalid: <why>`, `parked`) and its packet's parsed may-touch count and acceptance count, and spawns nothing.

## 3. Interfaces (signatures, not prose)

- `internal/yaml`: `func Parse(src []byte) (Node, error)`; `type Node struct{Kind Kind; Str string; List []Node; Map []KV; Line int}` with `type KV struct{Key string; Val Node}` preserving order; `Kind` in `Scalar, List, Map`; helpers `(Node) Get(key) (Node, bool)`, `(Node) String() (string, bool)`, `(Node) Int() (int, bool)`, `(Node) Bool() (bool, bool)`, `(Node) Strings() ([]string, bool)`. `type Error struct{Line int; Msg string}`. Corpus: `testdata/accept/*.yaml` each with a sibling `.json` of the expected tree; `testdata/refuse/*.yaml` each with a sibling `.err` holding the expected message prefix, at least eight refusals (anchor, multi-line `|`, nested flow, tab indent, duplicate key, unterminated quote, a list item under a scalar, a mapping value on the key's line with a nested mapping).
- `internal/packet`: `func Parse(path string, src []byte) (*Packet, error)`; `type Packet struct{ID, Title, From, Pin, Wall string; MayTouch []Glob; Acceptance []Line; Turns, Context, USD int; Sections [6]string; Bytes int}`; `type Glob struct{Raw string; Segs []string; Dir bool}`, `(Glob) Match(path string) bool` with the per-segment `*` semantics of `.hygiene-allow` (`fnmatch` per segment; `Dir` matches any deeper path); `type Line struct{Shell, Expect string; Kind ExpectKind; Value string; N int}` with `ExpectKind` in `Reads, ReadsOrMore, Under, Exits, AsMain`; `ID` is the file stem and must equal the `# Packet <ID>:` title id case-insensitively. Refusals, each an `error` naming the row or section: over 9,216 bytes; a missing or extra header row; a section out of order or missing; an acceptance item without an expectation; a may-touch span containing `**`; an unescaped `|` inside a span (the table would have split it). Fixtures: this repo's six packets copied at build time as `testdata/aN-*.md` plus a refusal per rule.
- `internal/queue`: `func Load(repo, path string) (*Queue, error)`; `type Queue struct{Version int; Defaults Row; Words string; Rows []Row; Hash string}`; `type Row struct{ID, PacketPath string; Packet *packet.Packet; DependsOn []string; Base, Model string; Turns, Context, USD int; Wall time.Duration; Merge, Device, Parked string}`; `func (q *Queue) Validate() []Problem` with `type Problem struct{Row, Msg string}`; `func (q *Queue) Order() ([]string, error)` a topological order honouring `depends_on` and `base`, `error` on a cycle naming a row on it; `func (q *Queue) External() []string` the ids named but absent. `Hash` is sha256 of the file.
- `relay/queue.yaml`: `version: 1`; `defaults` as §3's block; `words: ""`; the six rows `a3-machine` to `a8-night`, each `packet: design/packets/<id>.md`, `depends_on` and `base` as `design/packets/rows-2026-09-22.json` states them (same ids, same edges), `merge: branch-only`, `device: never`.
- `cmd/relay/main.go`: `plan [--queue PATH] [--json]`: loads the queue at `--queue` or `relay/queue.yaml` under the git toplevel, prints per row `row <id>: <state>; packet <path> (<n> may-touch, <m> acceptance lines); deps <ids or none>; base <id or main>` and a summary line; `--json`: `{"valid": bool, "queue": {"path","hash","rows": n}, "rows": [{"id","state","packet","may_touch": n,"acceptance": n,"depends_on": [],"base","external": []}], "problems": [{"row","msg"}]}`; exit 0 valid, 2 invalid or unreadable. `main_test.go` drops the `plan` stub row and adds a table over three fixture queues (valid, cycle, a missing packet).
