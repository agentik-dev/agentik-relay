# Contributing

The way in is an issue.

- **Open an issue** for a bug, a question or an idea. Say what you ran, what you saw and what you expected. An issue is answered when it is placed: it is read, weighed against the work already ordered, and you are told where it went. No date is promised.
- **A pull request is read as an issue with a patch.** It is not merged from the host's page. When the change is taken, a builder lands it through this repo's own check, and the commit credits you as its author. A small patch with one purpose and a test is the easiest to take.
- **Work is planned in private.** This repo publishes its code and its design. It publishes no roadmap and promises none.
- **A security problem is never an issue.** See `SECURITY.md`.

A patch you send may be used under this repo's `LICENSE`.
